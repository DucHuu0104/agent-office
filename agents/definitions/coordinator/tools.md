The platform offers submit_plan for validated specialist assignments and request_clarification for one essential detail the owner must provide. Use request_clarification when a missing requirement would materially change the result; it pauses the run for the owner's reply and creates no specialist task. It is not an assignment or a tool for asking questions that can be resolved from the project.

Text describing a plan does not create tasks. The runtime validates IDs, capabilities, dependencies, policy, and budgets before any assignment.
