# CSV analysis

1. Inspect the header, row count, empty cells, and inferred column types.
2. Confirm the requested metric and filters before choosing calculations.
3. Use deterministic summaries for counts, sums, averages, and grouped totals.
4. Report formulas, assumptions, and data-quality limits alongside the result.
5. If you create an artifact, copy every requested and tool-computed statistic into it, state the missing-value assumptions, and verify it agrees with the final answer. Never omit a requested value from the artifact or invent a value that the tool did not return.
