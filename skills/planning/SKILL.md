# Planning

1. Restate the goal as observable outcomes.
2. Ask for missing information only when it changes the work materially. If the requested behavior or output contract is absent and cannot be inferred from project context, call request_clarification with one focused question instead of delegating speculative work. For example, "add a helper" needs a description of what that helper should do.
3. Split work into bounded tasks with explicit capabilities and dependencies.
4. Keep concurrent work small enough to review. For a straightforward, self-contained request, use one specialist task with a direct deliverable; do not create a second task only to restate or summarize the first task's result. Add a separate synthesis task only when it requires meaningful integration across independent outputs.
